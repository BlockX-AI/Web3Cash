GrowStreams
The AI-verified quality streaming protocol.
Work is scored. Tokens stream. USDC follows.
Live on Vara Testnet
Core Model
Contributors do verified work → AI scores quality → GROW streams per second into wallet → USDC payout
Who Pays
Companies and DAOs deposit a campaign pool (e.g. $500 USDC)
Who Earns
Developers OSS PRs and creators X content — earnings proportional to quality score
Verification
LLM agent — GitHub PR rubric (Correctness 30%, Tests 25%, Quality 20%, Relevance 15%, Completeness 10%) + X engagement scoring
Payment Mechanism
Per-second streaming GROW token → USDC — Vara's $0.001/tx makes micropayments viable at scale
Anti-Gaming
AI quality threshold 70/100 enforced by LLM + velocity limits + identity binding (one wallet per GitHub/X)
Chain
Vara Network (Rust) + Canton (Daml) — Substrate-based L1 with parallel message processing
Existing Users
Zero — no live campaign yet. First campaign is the 21-day testnet launch.
Revenue Model
2.5% of all verified streaming volume. At $1M/month flow: $25K MRR
Identified Gap
No company-facing UI, no quest marketplace, no cashback mechanic for general crypto users. Protocol is proven — the B2B and consumer layers are entirely absent.
Web3Cash (proposed)
The performance marketing layer for Web3.
Complete quests. Earn USDC. Instantly.
Extension — 4-Week Build on GrowStreams
Core Model
Companies create quests → users complete on-chain actions → verified completion → USDC cashback paid instantly
Who Pays
Web3 projects running CPA CPI CPL CPS campaigns — escrow held before quests go live
Who Earns
Any crypto user — complete quests, earn real USDC cashback directly to wallet. No quality score required.
Verification
On-chain indexer Alchemy Moralis + social API checks — binary pass/fail, no LLM needed for standard quests
Payment Mechanism
Instant USDC payout on verified quest completion — 72-hour hold with unfollow re-check. Gnosis Safe escrow for MVP.
Anti-Gaming
Sybil scoring 8 signals via Gitcoin Passport + 72-hour hold + velocity limits + KYC gate at $500 cumulative
Chain
Multi-chain EVM Ethereum BNB Polygon Base Arbitrum
Market
Galxe 26M users, Layer3 1M+, Zealy, Intract — proven demand for quest-based crypto rewards
Revenue Model
15% margin on CPA + subscription tiers $5/$10/$25/mo + exclusive promo codes
Identified Gap
No AI quality verification — anyone can game low-effort quests. GrowStreams's LLM verification layer is the missing primitive Web3Cash needs to maintain payout integrity.
Strategic Fit Analysis
The gaps in each product are
precisely what the other already built.
01
Shared Identity Layer
GrowStreams's Identity Registry contract binds wallet ↔ GitHub/X on-chain. Web3Cash needs the exact same primitive. Zero rebuild required — the same contract serves both products.
100% Reuse · Live on Vara Testnet
02
AI Verification Layer
GrowStreams has LLM rubrics for quality scoring. Web3Cash's biggest gap is anti-gaming. Extend the existing pipeline: binary API checks for social quests, LLM scoring for content quests.
Extend · Replace LLM with API for simple quests
03
72h Hold = T+6h Pattern
GrowStreams re-evaluates X posts at T+6h and T+24h using BullMQ delayed jobs. Web3Cash's unfollow detection is the same pattern extended to T+72h. Same queue, same infrastructure.
Extend · BullMQ delayed job at T+72h
04
Market Distribution
GrowStreams has zero users but proven infrastructure. Web3Cash targets Galxe's 26M addressable users with a simpler UX. Web3Cash is GrowStreams's consumer distribution layer.
Web3Cash = GrowStreams's user acquisition engine
05
Campaign Economics
GrowStreams: 2.5% fee on streaming volume. Web3Cash: 15% margin on CPA. Combined: the same infrastructure monetises at 2 different price points for 2 different buyer types — developers vs marketing teams.
Combined ARR potential: $3M+ at scale
06
Build Once Principle
Telegram bot, Supabase schema, Railway deployment, Redis cache, anti-gaming dedup — built once, shared across both products. 68% of Web3Cash infrastructure exists in GrowStreams today.
4-week build · Not a 6-week rebuild
Executive Summary · April 2026
GrowStreams has no quest marketplace and no cashback layer. Web3Cash has no AI verification and no streaming infrastructure. These are not competing products — they are the B2B protocol and the consumer application of the same technical foundation. Building Web3Cash as an extension of GrowStreams eliminates 68% of the engineering work and ships a combined product in 4 weeks that neither team could build alone in under 10.
