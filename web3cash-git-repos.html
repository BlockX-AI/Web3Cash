03 — Anti-Sybil / Bot Prevention
The fastest integration
The Gitcoin Passport (now Human Passport) API gives you a 0–100 humanity score for any EVM wallet in 2 API calls, trained on millions of wallets and 2M+ passport holders. Free tier available. Integrating it is 10x faster than building your own scoring. Use it for MVP and build your own scoring in Phase 2.
Use this API
Sybil Resistance Protocol
passportxyz/passport
Gitcoin/Human Passport — the leading open source Sybil defense. ML models trained on ETH L1 + L2 on-chain activity vs known Sybil lists. Free API. 2M+ users already scored. You call GET /score/{wallet} → you get a human/bot classification back. Used by Galxe, Arbitrum, Uniswap.
⭐ 800+
TypeScript Python ML REST API
github.com/gitcoinco/passport | docs.passport.gitcoin.co

siwe (Sign-In with Ethereum)
EIP-4361 standard — sign "Login to Web3Cash" + nonce. npm install siwe → verify on server with siwe.verify(). The auth standard used by Galxe and Layer3.
🎮 Discord Member Verification
discord.js v14
getChatMember(guildId, userId) — verify user is in a Discord server. GUILD_MEMBER_REMOVE event for leave detection. Standard library, no specific repo needed beyond discord.js docs.
quest-chains/dapp
Has Discord guild role verification built in as one of the quest completion types. Reference this for your Discord quest type.
📬 Job Queue (72hr Hold)
BullMQ (npm)
bullmq.add('recheck', {completionId}, {delay: 72*60*60*1000}) — fires at exactly T+72hrs. Worker rechecks Twitter follow. On Upstash Redis for serverless. This is the core fraud prevention mechanism.
Upstash Redis
Serverless Redis for BullMQ. Free tier covers 10k commands/day — enough for MVP. Pair with Railway for the worker process.
The Minimum Shortcut — 3 Repos to MVP in 6 Weeks
If you only fork 3 repos
You do not need to study all 24 repos. For the 6-week MVP, start with these 3 and add modules from the others as you need them. Every other repo in this guide feeds into one of these three base projects.
01
scaffold-eth/scaffold-eth-2
Your entire app foundation
Fork this as your project base. You get wallet connect, Next.js 14, wagmi v2, RainbowKit, and Hardhat all pre-wired together. Add Supabase for your database and you have the full frontend + backend scaffold in one repo. Everything else plugs into this.
Fork first Day 1 7k stars
02
passportxyz/passport (API only)
Your entire Sybil layer
Don't build Sybil scoring from scratch. Call the Passport Models API: POST /score with a wallet address, get back a human/bot probability. Gate quests behind score > 20. Free tier. 2 API calls to integrate. This is what Galxe and Arbitrum use. Replace with custom scoring in Phase 2 if needed.
API call Week 1 Free tier
03
Uniswap/merkle-distributor
Your entire payout contract
Deploy the Merkle distributor for USDC payouts. Every 72 hours after the recheck passes, add the wallet to your Merkle tree. Users claim their USDC with a proof. Audited, battle-tested at Uniswap scale, MIT licensed. No need to write your own escrow contract for MVP.
Deploy contract Week 4 1k stars
Then add these 3 specific files from other repos
From RamiD22/phosphors → copy verify.js for Twitter OAuth + X follow check
From dabit3/nextjs-gitcoin-passport → copy pages/api/passport.ts for the Passport score fetch
From amicalhq/refref → copy the referral attribution logic for your 10% Level 1 referral tracking

Those three files + the three repos above = your entire MVP codebase. The rest is database schema (7 tables in Supabase), BullMQ jobs on Railway, and your UI.
